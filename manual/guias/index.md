# Guias

Receitas para tarefas específicas. Cada guia supõe que você já sabe se
autenticar; os exemplos usam `curl` com `Authorization: Bearer $TOKEN`. No
navegador, troque por `credentials: 'include'` e envie o `Origin` do frontend.
