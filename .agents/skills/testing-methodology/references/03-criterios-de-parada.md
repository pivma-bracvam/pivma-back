# Critérios de parada

Os testes de uma entrega estão completos quando:

- [ ] Cada história de usuário tem uma jornada descrita em prosa e um teste
  que percorre esse caminho pela interface pública.
- [ ] Cada passo da jornada verifica o que o usuário observa naquele momento.
- [ ] Cada requisito funcional tem ao menos um teste que prova seu
  comportamento.
- [ ] Cada erro esperado mapeado na matriz de risco tem um teste próprio.
- [ ] Os limites de autorização e isolamento foram testados com os perfis que
  devem ser negados, não só com o perfil permitido.
- [ ] Regras com ramificações foram exercitadas isoladamente.
- [ ] Consultas complexas têm teste de integração com dados reais.
- [ ] Todo defeito corrigido tem teste de regressão.
- [ ] A suíte foi executada e o resultado informado é o que de fato rodou.
- [ ] A cobertura não aponta buracos em código crítico.

Se um critério não se aplica, diga por quê. Se faltou executar algo, diga o
que faltou.
